Data Scientist | Software Developer

I am Filippo Morello, a Data Science student (Foundations of Artificial Intelligence and Machine Learning) at the University of Trieste. My passion lies in software development, both low-level and high-level, operating systems architecture, and data analysis.

I write C code handling memory management and parallelization; Java; Python for data analysis using Pandas and optimizations with NumPy; R for statistical computing; MATLAB for solving non-linear functions using numerical methods; and SQL for database querying. My primary development environment is Linux (Linux kernel) on GNU/Linux operating systems such as Arch Linux and Ubuntu (Debian). In the former, I have customized my setup using tools like Hyprland or i3, alongside Yazi, Kitty, Starship, and other software for a minimalist environment.

Beyond software development, I also dedicate my time to other interests such as sports, cinema, literature, and art. I am particularly drawn to sci-fi and thrillers that explore philosophical themes. As an avid chess player, I study theory and tactics, focusing on openings like the Queen's Gambit, Sicilian, and King's Indian. To stay active, I engage in swimming, running, and long-distance trekking, while my artistic side finds expression through human figure portraits drawn with pencils and ink.
